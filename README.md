# LINUXtips Workspace

My personal workspace for the **Linux para Cloud Native (LCN)** program by LINUXtips — a hands-on Linux/Cloud Native training track covering system administration, networking, and troubleshooting fundamentals for DevOps and Cloud Native roles.

## What's inside

- **`treinamentos/`** — Hands-on challenges completed during the course, including SSH access troubleshooting (fixing key-based authentication failures on a misconfigured server).
- **`mapas-mentais/`** — Mind maps summarizing key Linux and Cloud Native concepts for quick review.
- **`projeto-devops/logs/`** — Logs and notes from a DevOps project built as part of the training.
- **`entrevistas/`** — Mock interview notes and prep material tied to the course cohort (turma).

## Why this repo exists

This is a study log, not a production project — it documents my progression through Linux fundamentals as part of a broader DevOps/Cloud Native learning path (Linux → Docker → Kubernetes → CI/CD → AWS).
